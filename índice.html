Cómo añadir un módulo Python

Carpeta: ~/.nexus-ai/plugins/modules/ · Registro: ~/.nexus-ai/plugins/registry.json. Añade un archivo .py y una entrada JSON con id, name, entrypoint, description y approved:false. Revisa el código antes de cambiar approved a true. No se instala ni ejecuta código descargado automáticamente.
